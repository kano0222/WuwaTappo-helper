# 开发与维护

## 构建与交付

从仓库根目录运行 `.\scripts\Build.ps1`。助手使用 Windows 自带的 .NET Framework 编译器构建 x64 WPF 程序，最低支持 Windows 10 22H2 和 .NET Framework 4.8。选用 API 和 XAML 属性时按此环境核对。默认开发构建写入独立的 `build/X.Y.Z.N/`，显示为 `X.Y.Z.N-dev`；末位只区分本地构建。指定三位版本可用 `-Version X.Y.Z`。[构建脚本](../scripts/Build.ps1) · [验证选择](TESTING.md#选择验证)

**发布。** 在 [CHANGELOG](../CHANGELOG.md) 新增 `## [X.Y.Z] - YYYY-MM-DD`，测试版使用 `X.Y.Z-beta.N`。条目描述使用者能观察到的变化，同时供程序内更新窗口和 GitHub Release 使用。候选版本完成全量回归与关键场景验收后，按授权推送对应的 `v` 标签。[工作流](../.github/workflows/build.yml) 在 Windows 上构建、测试并检查包内资源，以同一次通过检查的 ZIP 发布；推送 `main` 生成构建产物。

**README 预览。** 有 FFmpeg 时运行 `.\scripts\Generate-ReadmePreview.ps1`，可用 `-FFmpeg` 指定程序路径，或用 `-Version` 生成指定版本的预览。脚本使用独立构建和模拟数据，复用真实面板渲染，在 `docs/images/` 输出完整面板动图和 Mini 静态图。[预览脚本](../scripts/Generate-ReadmePreview.ps1)

## 代码入口

[Panel](../src/Panel.cs) 将用户操作写成实例控制命令，[Worker](../src/Worker.cs) 按[策略](../src/Policy.cs)调度，经 [AppClient](../src/AppClient.cs) 调用[桌宠页面桥接](../src/Bridge)。状态和回执写回实例目录供面板读取。面板、托盘与命令行应复用已有控制链路，使同一操作经过相同的身份检查与恢复流程。

## 实例与连接

**后台互斥与控制身份。** 每个实例有独立的配置、命令和待确认记录；同一用户下的助手按桌宠路径互斥，防止不同目录重复接管。原生后台全程独占 `worker.guard`，取得锁后才可替换遗留标记。持锁足以阻止重复启动，控制命令还需把状态与运行标记中的目录、会话、PID 和创建时间对应起来。新后台可能已接替旧后台，因而只执行发给当前会话的命令。旧版 Node 后台仍按其运行标记和 PID 检查。[后台归属](../src/WorkerOwnership.cs)

**调试连接。** 显式启动桌宠时，通过 WebView2 宿主参数开启本机回环调试端口，保留用户已有的代理等环境设置。断线后只重连现有进程，尊重用户关闭桌宠的操作。WebView2 也可能由 Explorer 拉起，识别合法宿主需结合宿主绑定、浏览器签名和进程身份。探测期间持有已核实的进程句柄，防止 PID 复用导致归属改变。[启动](../src/Platform.cs) · [宿主识别](../src/HostedWebViews.cs)

优先用启动参数定位候选端口，并通过实际回环 TCP 连接核实服务端归属。参数不可用时，才从该实例的监听列表发现候选；只有一个候选通过 TCP 归属、CDP 主窗口验证和再次归属核验才能接受。参数歧义或归属无法核实时拒绝连接。这样既保留监听记录可能漏报时的参数路径，也避免连接到另一服。[端口发现](../src/Instances.cs)

## 账号操作与恢复

接口随桌宠版本变化。连接、版本变化及写入前检查所需能力，完整校验通过后再替换映射。操作前把发送意图写入实例的 `pending.json`。超时或断线可能发生在服务器处理之后，恢复时只核对原操作。补数已执行而保存失败时，恢复仅重试保存；人工确认校验并归档原记录。服务器强制等待与用户手动暂停均跨重试保留。[能力校验](../src/Capabilities.cs) · [补数](../src/Bridge/boost.js) · [恢复调度](../src/Worker.cs)

领取优先使用账号查询的累计值；查询落后时，仅采信仍与本地账目一致的同会话、同账号成功上报值。这样可保留尚未上报的点击增量，让原计数流程继续保存和上报。成功回执先同步有效的目标槽位冷却，活动保留回执时间；最终按同账号的扣数、槽位和奖励增量核验。两箱同时到期时，各自持久化发送意图与回执；左箱回执已落盘、本地扣数已安全应用后，再预检右箱，避免为第二箱等待滞后的账号查询。冷却拒绝 `70006` 由助手等待处理，保留原桌宠手动领取的提示行为。[单箱](../src/Bridge/claim.js) · [双箱](../src/Bridge/pair.js)

原桌宠的私有倒计时随前端版本变化，仅对已核实资源指纹的主窗口启用适配。适配只刷新目标槽位已过期的计时，界面适配失败仍按回执与账号数据核验领取结果。[倒计时适配](../src/Bridge/cooldown.js)

## 面板与更新

普通和 Mini 面板共用操作语义。主动 Tab 或 Shift+Tab 导航时显示按钮焦点，鼠标点击后恢复鼠标样式；Alt 和系统窗口切换保留原有焦点行为。可见标签已表达清楚时省去重复提示；纯图标含义容易混淆时，可用悬停提示说明动作，并提供读屏名称。[面板布局](../src/Panel.xaml)

实例配置、历史与待确认记录跟随助手目录。更新器校验附件摘要、分发文件清单和程序集版本，等待同目录各实例在操作边界退出后再替换文件，替换失败时尝试回滚。重开原窗口后由实例的自动运行设置决定是否启动后台，因此升级只替换分发文件，保留 `config.local.json` 和整个 `runtime/`。[更新安装](../src/UpdateInstaller.cs)
